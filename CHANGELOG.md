# Changelog

All notable changes to Stash Toolkit are documented here, newest first.
This list mirrors the "What's New" entries kept inside the app itself
(About tab), which is the toolkit's source of truth for its own history --
versions older than 5.1.287 were not retained there and aren't listed below.

- New Rescan button next to the library stat cards -- re-pulls Scenes/Groups/Performers/Images/Studios from Stash without a full Disconnect/Connect
